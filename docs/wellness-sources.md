# 休息引导依据（2026-09-07）

- AAO EyeWiki, Computer Vision Syndrome (Digital Eye Strain): https://eyewiki.aao.org/Computer_Vision_Syndrome_(Digital_Eye_Strain)
  用于支持屏幕间歇休息、远眺和眨眼的一般方向。界面文字为原创简短引导，无治疗或预防近视承诺。
- NHS, Sitting exercises: https://www.nhs.uk/live-well/exercise/sitting-exercises/
  用于坐姿、稳固无轮椅子与脚踝轻柔活动。动作自行选择，不以完成次数作为休息奖励条件。
- Cambridge University Hospitals, Frozen shoulder: https://www.cuh.nhs.uk/patient-information/frozen-shoulder/
  参考其中缓慢肩部滚动动作；应用不作为冻结肩治疗方案，不照搬治疗频率或强度。

设计选择：每段引导后安静休息；允许停做；不揉眼或按压眼球、不强制大幅颈部旋转、不屏息、不追踪屏幕移动目标。时间安排为产品节奏设计，不是医疗处方。

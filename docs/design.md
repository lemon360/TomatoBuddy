# 设计与实现

用户要求 Windows 11 本地番茄钟，参考护眼宝，素材使用 AI 绘画；用户选择可爱治愈风。

选择 WPF 原生桌面实现，相比 Electron 不需要携带浏览器运行时，相比浏览器应用可直接使用 Windows 托盘与窗口。独立目录中实现，未修改其他现有项目。

界面分为专注、统计、设置；奶油背景配暖番茄红及鼠尾草绿。专注区域提供状态圆环、任务命名、开始暂停与重置。右侧原创番茄角色陪伴插画和今日统计。

TimerEngine 独立管理阶段、UTC 截止时间与完成事件；界面以 250ms 调度更新显示。完成事件保存一次数据，决定下个阶段，按设置通知或显示休息窗口。LocalStore 使用 JSON 临时文件后替换，读取异常尝试保存恢复副本。

仅完整专注阶段纳入统计，暂停、重置、切换和休息均不会增加番茄数。切换及重置未完成一轮时提示确认，以防误操作损失进度。
